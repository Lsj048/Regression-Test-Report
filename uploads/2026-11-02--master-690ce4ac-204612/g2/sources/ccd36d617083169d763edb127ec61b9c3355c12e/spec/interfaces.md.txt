# 界面与子智能体边界

本文件是规范性文件。适用范围、术语及变更规则见[规范入口](README.md)。

<a id="edge-01"></a>

## EDGE-01 界面通用、独立且可整体替换

网页、终端和无界面入口使用同一模式装配及稳定命令、事件和投影；不得各自拼装能力、解释策略私有状态、直接写核心数据库或拥有业务仲裁。界面由独立的界面层实现，通过通用协议展示消息、工具结果、公开状态和人工交互，可以整体替换而无需修改领域工具和策略。

领域扩展通过公共协议贡献文字、结构化展示数据及交互声明，并解释回答的业务含义；不得拥有或向页面注入前端组件、样式或可执行渲染代码。界面层可以识别公开展示类型及版本，为目标等能力选择专用呈现；渲染实现及其选择属于界面层。界面不得导入领域内部源码或类型，不读取私有状态，不推导批准、完成等业务结论，也不直接执行领域命令。

使用已有公共协议新增或移除领域能力时，公共传输、事件投影及执行协调无需修改；默认通用展示可以直接承载，界面也可以增加可选专用视图。移除专用视图或替换整套界面后，仍能通过通用内容和操作完成相同流程，不要求领域修改。当前入口不能承载某项必需交互时须明确报告不可用，不得静默隐藏已选工具、伪造回答或扩大授权，遵守 [MOD-02](boundaries.md#mod-02) 和 [STA-05](lifecycle.md#sta-05)。

公开视图通过通用数据通路提供，并随其权威来源更新或撤回；该通路不要求把视图或业务数据另存一份，遵守 [DATA-06](persistence.md#data-06)。展示声明可带 `view: { type, version, data }`，提供有版本的结构化数据，核心和宿主只校验、传递通用外壳，不认识目标等具体类型。专用视图不支持某类型、版本或数据时回退到 `content`；所有声明保留可用的通用内容、字段与操作。不得传送组件代码或把展示类型当作授权。

通用展示声明必须为带版本的纯数据：文字、键值、列表、进度和分组，文本、选项和开关字段，以及可选的公开展示数据。同步回答操作只能组合领域声明的固定回答值与指定输入字段，输入不得覆盖固定值；字段是否必填、合法选项及最终回答格式由宿主再次校验。未知主协议版本、未知必需控件及不可支持的必需回答在进入等待前明确拒绝；未知可选展示类型或版本使用通用内容。不能要求用户手写结构化数据作为默认交互。网页与终端对同一声明产生相同回答编码，专用呈现不得改变回答含义或授权。

公开操作声明仅允许通用的输入提交或中断后提交；界面只提交所有者、视图对应的来源版本、操作标识和幂等标识，由宿主通过通用契约核对当前有效视图及实际命令，不能执行客户端自行拼接的领域命令。来源版本改变或视图撤回后，旧操作必须拒绝；版本校验和操作接收必须有一致性保证，不能在校验后用已失效的状态启动操作。无需为此重复保存整份展示正文。回答收据与领域执行结果分别展示，不由通用页面解释回答中的领域字段来推导业务成功。历史声明的格式转换由拥有它的扩展提供纯数据适配，宿主通用装配，不能把旧领域分支保留在界面层。

网页用量等只读汇总应从宿主公开的已提交审计事实派生，不能从裁剪后的聊天正文或流式片段推算。通用审计查询保留原事件身份、来源会话和顺序，覆盖子会话及不属于轮次的事实；按类型和游标读取有界数量，非法游标或条数明确拒绝，读取及重建不得产生业务写入。分类、日期布局和调用者摘要由界面层拥有，遵守 DATA-06。

网页文件与文件夹选择使用操作系统原生窗口；取消必须关闭窗口、清除界面忙碌状态且不添加附件，之后可以再次打开。预先准备辅助进程不得展示窗口，辅助进程异常时当前请求明确失败并允许下次重试。

<a id="edge-02"></a>

## EDGE-02 子智能体复用同一执行语义

子智能体使用同一内核、状态机、消息与事件规则，保留父子及触发因果关系；基础绑定继承父级，能力过滤和权限只能收窄，不得突破父级作用域、深度或宿主上限。创建、跟进、等待、取消及恢复不能另造一套内存专用执行循环。中断单个子智能体只影响指定执行；根级中断须传播到活动后代。

<a id="edge-03"></a>

## EDGE-03 交互验收追到执行事实

测试界面动作时，必须检查其对应输入、轮次、工具执行或权限事实及恢复后投影，不能只检查按钮或文本。内部完成通知不得冒充用户授权或长期偏好证据；公开视图来自其声明的权威来源，流式画面来自易失快照，两者不能混作持久完成。
