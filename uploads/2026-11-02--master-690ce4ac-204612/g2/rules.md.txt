# G2 消息结构规则

仓库版本 SHA：`ccd36d617083169d763edb127ec61b9c3355c12e`

| 规则 ID | 标题 | 自然语言描述 |
| --- | --- | --- |
| G2-001 | 系统消息的位置 | 对话请求最多包含一条 system 消息，放在消息列表最前面。 |
| G2-002 | 系统提示词的拼接 | 基础 system 正文在前，追加的系统片段在后，非空片段之间用一个空行分隔。 |
| G2-003 | 系统片段的顺序 | 追加的系统片段按声明的 order 从小到大排列，order 相同时按片段标识的英文排序规则排列。 |
| G2-004 | 直接工具的声明 | 模型可直接调用的工具，其名称、description 和参数 Schema 放在请求的 tools 字段中，与 messages 并列。 |
| G2-005 | 工具的补充说明 | 工具额外提供的使用指导放在 system 消息中。 |
| G2-006 | 程序入口的工具声明 | 通过程序入口间接调用工具时，请求的 tools 中只允许出现获准的程序入口。 |
| G2-007 | 嵌套工具说明的位置 | 供程序内部调用的工具，其契约说明放在 system 消息中。 |
| G2-008 | 时间信息的位置 | 时间信息作为本轮输入对应 user 消息的一部分，隔一个空行追加到正文末尾。 |
| G2-009 | 临时上下文的排列 | 多条临时上下文放在历史的同一侧时，按各自标识的英文排序规则排列。 |
| G2-010 | 项目说明的位置 | 加载的项目说明作为独立的 user 消息，放在 system 之后、对话历史之前。 |
| G2-011 | 项目说明变更提醒的位置 | 项目说明发生变化时，变更提醒作为独立的 user 消息，放在对话历史之后。 |
| G2-012 | 技能目录的位置 | 可用技能的目录信息放在 system 消息中。 |
| G2-013 | 规划入口提示的位置 | 规划入口指导作为独立的 user 消息，放在对话历史之前。 |
| G2-014 | 规划状态的位置 | 当前规划状态或已批准的执行范围作为独立的 user 消息，放在对话历史之前。 |
| G2-015 | 批准计划后的历史替换 | 批准计划并选择清理上下文时，用一条包含已批准计划的 user 消息替换此前的非 system 对话历史。 |
| G2-016 | 目标状态的位置 | 当前目标状态作为独立的 user 消息，放在对话历史之后。 |
| G2-017 | 长期记忆的位置 | 召回的长期记忆非空时，作为独立的 user 消息，放在对话历史之前。 |
| G2-018 | 续写提示的位置 | 触发续写时，续写提示作为独立的 user 消息，放在对话历史之后。 |
| G2-019 | 完整压缩的摘要 | 完整压缩成功后，用一条 user 摘要消息替换被压缩的历史范围。 |
| G2-020 | 微压缩的工具结果 | 微压缩替换选中工具结果的正文，保留 tool 角色和原工具调用 ID。 |
| G2-021 | 转存结果的位置 | 成功转存后的结果预览和文件引用保留在对应工具调用的 tool 结果中。 |
| G2-022 | 工具调用的位置 | 模型发起的工具调用保留在 assistant 消息的工具调用字段中。 |
| G2-023 | 工具结果的关联 | 每条 tool 消息通过工具调用 ID 关联前面 assistant 消息中的对应调用。 |
| G2-024 | 缺失工具结果的补齐 | 工具调用缺少结果时，在下一条非 tool 消息之前或消息列表末尾补入对应的 tool 中断结果。 |
| G2-025 | 孤立工具结果的处理 | 无法匹配到前面工具调用的 tool 结果不进入模型请求。 |
| G2-026 | 推理内容的位置 | assistant 的推理内容放在独立的推理字段，与可见回答正文分开。 |
| G2-027 | 工具图片的位置 | 模型支持图片时，连续一组 tool 结果中的图片移到该组之后的一条独立 user 消息中。 |
| G2-028 | 不支持图片的输入 | 模型不支持图片时，图片内容块转换成文字内容块。 |
| G2-029 | 子任务协作说明的位置 | 子任务通知的处理说明放在 system 消息中。 |
| G2-030 | 子 Agent 人设的位置 | 子 Agent 的人设非空时，人设内容放在该子 Agent 的 system 消息中。 |
| G2-031 | 子 Agent 身份的位置 | 子 Agent 的受委派身份说明放在其 system 消息中。 |
| G2-032 | 后台子任务状态的位置 | 尚未结算的后台子任务状态说明放在 system 消息中。 |
| G2-033 | 子任务完成通知的位置 | 后台子任务完成通知作为独立的 user 消息进入父 Agent 会话。 |
| G2-034 | 任务清单提醒的位置 | 任务清单提醒追加到选中的原 tool 结果或本轮真实用户输入末尾，保持原消息角色。 |
| G2-035 | 提醒与时间的顺序 | 同一条 user 消息同时有任务清单提醒和时间信息时，顺序为原正文、任务清单提醒、时间信息。 |
| G2-036 | 辅助请求的消息 | 辅助模型请求使用各自构造的消息列表，不自动继承主对话上下文。 |
| G2-037 | 辅助请求的工具 | 通过公共补全服务发起的辅助请求，其 tools 为空，工具选择设置为 none。 |
